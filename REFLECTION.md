This assignment included Tkinter, validation logic, creating a GUI, and serializing data into JSON and performing HTTP POST requests. A Flask API received the data, a Tkinter window collected it, and JSON was used as the format to connect them. I performed the steps below:

#1. Build the API
#2. Lay out the form widgets
#3. Validate the input locally
#4. Convert the form to JSON, and POST it to the API

Something that surprised me was that initially I did not have to use a complete name, or at least a first name to create a record. I used this opportunity to learn how to add code making it necessary for the name to be letters and at least 5 characters. My code evolved from making a name/email form to making a purchase form with more fields. It also included a price check and the name code change on both the client and the server, because the server shouldn’t trust the client alone. I have a better understanding of data binding, JSON serialization, HTTP status codes, and input validation. I would like to learn more about databases for storing the purchases and how to secure an API.
